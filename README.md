# PS 套图工作台

Windows 桌面工具，连接已经打开的 Photoshop，批量替换 PSD、PSB、TIF/TIFF 模板中的智能对象，导出 JPG、PNG 和分层 PSD。

## 下载与启动

- 当前版本：**V2.1.2**。
- [下载 V2.1.2 单文件 EXE](https://github.com/wengdajie/PS-auto-suite-tool/releases/download/v2.1.2/PS-Auto-Suite-Rust-v2.1.2.exe) · [查看最新版本](https://github.com/wengdajie/PS-auto-suite-tool/releases/latest)。
- Windows 10/11，64 位；需安装可运行 ExtendScript/JSX 的 Photoshop。已在 Photoshop CC 2018 实测。
- 下载一个 EXE 即可双击使用，无需另外安装 Python、Rust 或手动解压运行库。首次启动会在当前用户的本地应用数据目录准备内置文件。
- 先打开 Photoshop，再打开工具。两者使用相同权限级别。

本仓库发布软件说明与可执行程序；本次不上传应用源码。

## 使用流程

1. 选择单模板、多模板或制衣模式，设置模板路径。
2. 点击“读取智能对象”，检查图层映射。图号 `1` 对应本轮第 1 张素材，`0` 表示保留该槽位原图。
3. 选择素材目录和导出目录，点击“扫描目录”，核对张数与轮数。
4. 打开“命名规则与更多设置”，检查目录规则、文件名规则和对应的输出路径预览。
5. 点击“添加到队列”，再点击“开始套图”。

队列任务保存加入时的参数。修改命名或导出设置后，请选中已入队任务并点击“更新选中”，或重新添加任务。

## 素材分轮规则

### 直接选择包含图片的文件夹

素材按自然顺序连续分组，每轮用图数量由智能对象映射决定。常规连续图号下，轮数为 `素材张数 ÷ 智能对象数量` 向上取整。

| 素材数量 | 每轮槽位 | 运行轮数 |
| --- | --- | --- |
| 6 张 | 1 个 | 6 轮 |
| 6 张 | 2 个 | 3 轮 |
| 7 张 | 2 个 | 4 轮，末轮仅替换 1 个槽位 |

素材不足完整一轮时仍处理已有图片，缺图槽位恢复模板原始内容，不沿用上一轮图片。手动图号有间隔时，以最大正图号作为每轮素材跨度；`0` 不增加跨度。

### 选择包含素材子文件夹的上级目录

每个含图片的直接子文件夹独立一轮。超出槽位的图片不参与该轮，不足时保留对应槽位原图；不跨目录取图，不递归到更深层目录。有子文件夹时，根目录中的散图不参与处理。

## 文件夹名称与默认导出结构

“批次名”由素材组织方式决定：

| 素材组织 | 批次名来源 | 示例 |
| --- | --- | --- |
| 平铺，1 个槽位 | 本轮图片文件名，不含扩展名 | `静物 (1).png` → `静物 (1)` |
| 平铺，多个槽位 | 本轮各图片名，用 `__` 连接 | `静物 (1)__静物 (2)` |
| 素材子文件夹 | 原子文件夹名 | `场景1` |
| 制衣模式 | 素材目录名与尺码 | `花色A_XL` |

目录规则与文件名规则均为 `<auto>` 时，普通单模板示例：

```text
所选导出目录/
  单图模板/
    静物 (1)/
      单图模板_01.png
      单图模板.psd         # 开启“同时保存分层 PSD”时
    静物 (2)/
      单图模板_01.png
```

普通多模板示例：

```text
所选导出目录/
  模板组/
    静物 (1)__静物 (2)/
      主图/
        主图_01.png
      详情/
        详情_01.png
```

实际导出模板多于一个时才追加模板子目录。制衣模式按产品目录组织，默认图片文件名为 `素材目录名_尺码.jpg/png`，分层文件为同名 `.psd`。

## 设置中的命名规则

### 1. 目录结构

只控制导出目录下的文件夹层级，`/` 分隔层级。自定义规则生效后，不会额外追加默认任务目录。

| 设置内容 | 对应效果（假设本轮素材为“静物 (1)”，模板为“主图”） |
| --- | --- |
| `<auto>` | 使用上文默认结构 |
| `{batch}` | `所选导出目录/静物 (1)/` |
| `{batch}/{template}` | `所选导出目录/静物 (1)/主图/` |
| `{template}` | `所选导出目录/主图/` |
| `{material}/{image}` | `所选导出目录/图片/静物 (1)/` |
| 留空 | 直接输出到所选导出目录 |

### 2. 文件命名

只控制已选定目录内的文件名，不需要填写扩展名。

| 设置内容 | 对应图片文件名 |
| --- | --- |
| `<auto>` | 普通模式：`主图_01.png`；制衣：`花色A_XL.png` |
| `{template}_{slice_index}` | `主图_01.png` |
| `{image}_{slice_index}` | `静物 (1)_01.png` |
| `{slice_index}` | `01.png` |
| `{template}_{image}_{slice_index}` | `主图_静物 (1)_01.png` |

图片后缀由 JPG/PNG 设置决定。自定义文件名中，分层 PSD 的 `{slice_index}` 为 `psd`，合并图为 `merged`。例如 `{image}_{slice_index}` 对应 `静物 (1)_psd.psd` 和 `静物 (1)_merged.png`。

### 3. 变量逐项对应

设置中会显示以下每个变量的含义，以及基于首个任务、首轮素材、首个导出模板计算出的预览值。尚未选好路径时明确使用示例数据，不会冒充实际输出。

| 变量 | 对应内容 | 示例 |
| --- | --- | --- |
| `{batch}` | 平铺为本轮图片名组合；子目录为原目录名；制衣为素材名_尺码 | `静物 (1)` / `静物 (1)__静物 (2)` / `场景1` |
| `{image}` | 本轮第一张素材名，不含扩展名 | `静物 (1)` |
| `{image_index}` | 本轮第一张素材在整批素材中的序号，从 1 开始 | `1`、`3` |
| `{template}` | 当前模板名，不含扩展名 | `主图` |
| `{material}` | 当前素材文件夹名，所有模式可用 | `图片` / `场景1` |
| `{size}` | 模板识别出的尺码，或唯一指定尺码；没有时为空 | `XL` |
| `{slice_index}` | 当前导出序号，使用补零与起始序号设置 | `01` / `001` / `00` |
| `{slice_count}` | 实际导出切片总数，使用补零设置 | `03` |
| `{date}` | 实际任务开始日期 | `20261026` |
| `{time}` | 实际任务开始时间 | `143025` |
| `{ext}` | 当前文件实际格式 | `jpg` / `png` / `psd` |

`{slice_index}`、`{slice_count}` 在目录规则中按空值处理；目录中的 `{ext}` 取主图片格式，PSD 保存在同一目录。预览中的切片总数为示例值，实际值由 Photoshop 模板决定；日期与时间以实际运行时为准。

- 序号补零位数为 1–4，起始序号可选 0 或 1。
- 文件名非法字符会替换为 `_`；目录规则不能使用盘符、绝对路径或 `..`。
- 同名文件自动追加 `_2`、`_3` 等后缀，保留已有结果；不会直接覆盖。

## 导出、授权与更新

- JPG/PNG 与“同时保存分层 PSD”独立设置。
- 开启 Save for Web 后，有用户切片按模板切片导出；明确没有用户切片时直接导出整图。
- 图层映射支持拖拽、删除和 `0` 跳过；文案可通过表格逐轮替换，表头对应文字图层名。
- 卡密验证界面提供“自助换绑”，成功后在目标设备重新验证。实际是否允许换绑由授权服务决定。
- 启动时后台检查本仓库最新正式 Release，高于当前版本且 EXE 附件已就绪时弹窗；设置中也可“检查更新”。点击“前往下载”打开对应发布页，完成当前任务后使用新 EXE。
- 更新检测不发送卡密或项目内容；网络失败会显示提示，不影响套图功能。
- 问题排查时请提供当前版本、队列日志和实际命名设置，便于核对不同设备使用的规则。
